# Architecture and retained research index

These links retain the original architecture discovery map. Historical probes are evidence for their stated experiments, not qualification of the current implementation. In particular, issue #15 infrastructure was retired. Current qualification is recorded in [the implementation record](../implementation/issue-20.md).

The [GitHub architecture map](https://github.com/09millarda/agents-assemble/issues/1) is the single canonical index of decisions and unresolved questions.

- [Product charter](../product-charter.md): requirements, proposed terminology, and the two starting playbooks.
- [First release contract](../first-release-contract.md): owner-approved pilot scope, collaboration/community features, Lambda delivery journey and release qualification targets from #4.
- [Domain context](../../CONTEXT.md): candidate ownership boundaries and architectural constraints.
- [Control plane and runner boundary](./0001-control-plane-and-runners.md): the first decision and its limits.
- [Playbook and action contract](./0002-playbook-and-action-contract.md): versioned definitions, structured execution, approval and recovery semantics; [illustrative definitions](../examples/playbook-contract.md).
- [Playbook conformance experiment](../research/playbook-conformance.md): retained grammar, evidence-backed amendments and limits from disposable mock authoring/recovery probes; production durability remains to validate.
- [Durable execution and recovery](./0003-durable-execution-and-recovery.md): PostgreSQL acceptance transactions, participant ownership, waits, fencing and publication recovery; [fault-injection evidence](../research/durable-execution-conformance.md) and [substrate comparison](../research/durable-substrate-comparison.md).
- [Runner assignment and checkpoint recovery](./0004-runner-assignment-and-checkpoint-recovery.md): durable local receipts, launch uncertainty, result replay and verified fresh-session reconstruction; [daemon and native-harness evidence](../research/runner-recovery-conformance.md), including the observed tool process surviving App Server termination.
- [Native-writer supervision](./0005-native-writer-supervision.md): retained delegated payloads, scoped stop receipts and takeover gates; [native, Linux and durable-protocol evidence](../research/native-writer-supervision.md), including a writer outside an empty service cgroup.
- [Enrolled-runner authority](./0006-enrolled-runner-authority.md): mutual TLS, scoped observer authorization, immutable receipt history and revocation boundaries; [source comparison](../research/runner-authority-sources.md) and [authentication evidence](../research/runner-authority-conformance.md).
- [Collaborative drafts and revision submission](./0007-collaborative-drafts-and-revision-submission.md): Yjs drafts, durable acceptance, exact review candidates and explicit Execution observation/adoption; [comparison](../research/collaboration-substrate-comparison.md) and [conformance evidence](../research/collaborative-drafts-conformance.md). The subsequent graph decision is ADR 0008.
- [Semantic graph collaboration](./0008-semantic-graph-collaboration.md): stable editor entities, ordered placements and exact conflict/publication gates; [two-replica and authoring evidence](../research/semantic-graph-conformance.md) preserves the supported grammar while leaving the production editor and validator unproved.
- [Shared harness conversation](./0009-shared-harness-conversation.md): ordered attributed inputs, one-use dispatch claims, exact-turn control and conservative replay/redirect; [native and durable evidence](../research/shared-conversation-conformance.md) demonstrates duplicate client IDs and preserves interruption/recovery limits.
- [Portable community publication and moderation](./0010-portable-community-publication.md): owner-approved organization publishing, exact public snapshots, immutable offline imports, feedback/moderation and independently enforced quarantine holds; the bounded envelope/verifier contract follows in ADR 0012.
- [Open-source licensing and edition parity](./0011-open-source-licensing-and-edition-parity.md): owner-selected Apache-2.0, full self-hosted parity, DCO contributions and open-source public software packages; distribution/license application remains separate.
- [Portable package envelope and verification](./0012-portable-package-envelope-and-verification.md): strict stored ZIP, canonical metadata, complete offline closures, current local issuer trust and exact public ancestry; [conformance evidence](../research/portable-package-conformance.md) separates actual byte/signature/SQLite checks from reduced semantic and policy fixtures.
- [Protected observer and retained-scope recovery](./0013-protected-observer-and-retained-scope-recovery.md): root-separated keeper/reporter custody, exact scoped receipts and conservative failure; [native evidence](../research/protected-observer-conformance.md) demonstrates reporter restart and mTLS replay while an outside writer keeps automatic takeover ineligible.
- [Lambda deployment experiment plan](../research/lambda-deployment-plan.md) and [provider research](../research/lambda-deployment-sources.md): [actual GitHub-to-AWS identity verification passed](../research/aws-github-connection-result.md) for Proof of Concept; Ireland access is enabled. [Actual staging/promotion, failed-health and artifact-restoration probes passed](../research/lambda-live-deployment-result.md); [GitHub dispatch recovery and controlled durable claim tests](../research/deployment-authority-result.md) also passed. [Signed GitHub identity now reaches the claim gate](../research/deployment-oidc-claim-result.md) in a trusted job. The independent approval-to-AWS bridge and provider fault qualification remain open.
- [Project scope and run admission](./0014-project-scope-and-run-admission.md): Projects owns registrations and policy; Execution freezes each admitted run. Multiple repositories per project and one writable repository per run are the stated first-release planning default; [consistency review](../research/project-admission-review.md) and [bounded conformance evidence](../research/project-scope-conformance.md) record the documentary and reduced local-runtime results.
- [Harness research](../research/harness-capabilities.md), [environment delivery](../research/environment-delivery.md), and [failure review](../research/runtime-failure-review.md): evidence supporting the first decision.
