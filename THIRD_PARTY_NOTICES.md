# Third-party components

The exact locked dependency inventory is generated by `npm run inventory` into `docs/distribution/dependencies.json`. Distribution builds include that inventory, `THIRD_PARTY_LICENSES.txt` with upstream license and notice texts, and `THIRD_PARTY_LICENSES.json` mapping installed package versions and integrity to those texts. This conservative collection includes installed production dependencies across the product, emitted Tailwind CSS, and additional dependencies identified by the runner bundler; it does not claim that every listed package is embedded in each output. Uninstalled optional packages appear only in the complete lock inventory. Production bundles also retain legal comments.

Two dependencies (`pg-types` and `pgpass`) carry their complete MIT terms in their installed README rather than a separate license file. `react-remove-scroll-bar` 2.3.8 declares MIT but omits the full terms from its npm archive; the build retains its [upstream license at commit 8ca9ba5ea52de03308fe8ced94f7b159a44d28ff](https://github.com/theKashey/react-remove-scroll-bar/blob/8ca9ba5ea52de03308fe8ced94f7b159a44d28ff/LICENSE), with a checked content digest. License collection is offline and rejects unknown missing terms or installed versions that differ from the lockfile.

The web application includes components generated from shadcn/ui (radix-nova) using CLI 4.21.0. Those components remain subject to the MIT license below. They were adapted to this application's layout, imports and forms.
