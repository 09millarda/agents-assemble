- `fixtures/`: six real harmless Linux process/service experiments; three separately modeled guard examples.
- `native/`: four actual Codex 0.153.4 native-account turns; two retained-payload empty receipts, two plain-service stop observations; independent archive/integrity review.
- `protocol/`: separate SQLite receipt/admission model with actual process-death barriers; trusted supervisor, principal and checkpoint inputs are explicitly modeled.
- `writer-supervision-lab.html`: standalone illustrative state explorer plus complete recorded evidence. It is not an empirical adapter test.
